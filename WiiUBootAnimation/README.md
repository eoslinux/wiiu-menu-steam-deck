# Wii U Startup Movie

Конвертированная видеозаставка для Steam Deck (VP8/WebM, 1280×800, 30 fps, со звуком).

## Установка

1. Скопировать `deck_startup.webm` в:

   ```
   /home/deck/.steam/root/config/uioverrides/movies/
   ```

2. Steam → **Настройки** → **Кастомизация** → **Видеозаставка**.
3. Выбрать **`deck_startup.webm`** (локальный файл).

Файл уже установлен и выбран на этом Deck.

## Технические параметры

- контейнер: WebM
- видео: VP8, 1280×800, 30 fps, ~3 Мбит/с
- аудио: Vorbis, stereo, 128 кбит/с
- длительность: ~16.2 с
- исходник: `Nintendo Wii U - Startup Intro.mp4` (1280×720), поля сверху/снизу залиты белым под 16:10
