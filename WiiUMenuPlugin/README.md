# Wii U Menu — Decky plugin

Полноэкранное меню Wii U для Steam Deck. Это уже не CSS-тема и не оверлей поверх карусели: плагин рисует собственный интерфейс прямо в Big Picture, скрывает родной Home и показывает сетку каналов.

![Превью](preview/preview.png)

## Что умеет

- сетка каналов 5×3 (15 игр на страницу), недавние игры первыми;
- запуск игры по A / клику;
- страницы: L1/R1, стрелки по бокам, PageUp/PageDown;
- живые часы и дата в нижней панели;
- индикатор батареи и Wi-Fi под датой;
- полоска громкости, которая обновляется при изменении звука;
- логотип Wii U, точки страниц;
- звуки: тик фокуса, выбор, назад, перелистывание, запуск игры (синтезированы через Web Audio, без аудио Nintendo);
- кнопка «Wii U» в QAM: включение/выключение замены Home и звуков.

## Управление

| Кнопка | Действие |
|---|---|
| D-pad / левый стик | выбор канала |
| A | запустить игру |
| B | показать Steam (закрыть меню) |
| L1 / R1 | предыдущая/следующая страница |
| QAM (`...`) | Decky → Wii U Menu: настройки |

Если D-pad или стик не двигают выделение — напишите, добавлю отдельный мост через Steam Input (в некоторых сборках Steam сырые события стика приходят иначе).

## Установка

Плагин уже установлен в:

```
/home/deck/homebrew/plugins/WiiUMenuPlugin
```

CSS-тема `WiiUMenu` из CSS Loader для этого меню не требуется: плагин полностью рисует свой интерфейс. Её можно оставить как оформление родного Home, которое видно после нажатия B, или отключить.

Для ручной установки скопируйте папку `WiiUMenuPlugin` в `/home/deck/homebrew/plugins/` и перезапустите Decky Loader (или перезагрузите Deck).

## Как выйти из меню

- **Steam** (кнопка слева от экрана) → **Питание** → **Рабочий стол**.
- **B** закрывает меню и показывает обычный Home.
- Иконка **монитора** рядом с конвертом внизу справа сразу переключает в рабочий стол.
- QAM (`...`) → **Decky** → **Wii U Menu** → **Перейти в рабочий стол**.
- Если ничего не реагирует: удерживайте кнопку питания ~10 секунд и включите Deck заново.

## Видеозаставка при запуске

Рядом лежит `WiiUBootAnimation.zip` и файл `deck_startup.webm`. Он уже установлен в

```
/home/deck/.steam/root/config/uioverrides/movies/deck_startup.webm
```

и выбран в **Настройки → Кастомизация → Видеозаставка → `deck_startup.webm`**. Это WebM/VP8 1280×800 со звуком.

## Если что-то пошло не так

Меню скрывает родной интерфейс через `#popup_target` и класс `wiiu-menu-open`, а само живёт в отдельном слое над ним. QAM и меню Steam — отдельные окна, поэтому они остаются доступны.

1. Нажмите `...` (QAM) → **Decky** → **Wii U Menu**.
2. Выключите **Заменять главный экран** — вернётся родной Home.
3. Если QAM не открывается, перезагрузите Deck: плагин при старте ничего не скрывает, пока меню не отрисовано.
4. Полное удаление: Decky → Plugins → Wii U Menu → Uninstall, либо удалите папку `WiiUMenuPlugin` из `/home/deck/homebrew/plugins/`.

В QAM видно текущий маршрут Steam (`Маршрут: /library/home`). Если меню не появляется само, но кнопка «Открыть меню Wii U» работает — пришлите этот маршрут, поправлю автоопределение.

## Сборка

```bash
npm install
npm run build
```

`dist/index.js` — готовый бандл. Шрифт Nunito вшит в бандл в base64, интернет для него не нужен.
