# Wii U Menu — тема для CSS Loader

Тема для Steam Deck в стилистике домашнего меню Wii U: светло-голубая «бумажная» подложка, белые глянцевые плитки, голубое свечение выбранного канала, полупрозрачная верхняя панель и чистая нижняя панель.

> Это фанатская CSS-тема. Она не содержит графики Nintendo, не связана с Nintendo или Valve. «Wii U» — товарный знак Nintendo.

![Превью темы](preview/preview.png)

## Установка

1. Переключите Steam Deck в режим рабочего стола (**Steam → Питание → Рабочий стол**).
2. Скопируйте папку `WiiUMenu` целиком в:

   ```
   /home/deck/homebrew/themes/
   ```

   Должно получиться так:

   ```
   /home/deck/homebrew/themes/WiiUMenu/theme.json
   /home/deck/homebrew/themes/WiiUMenu/shared.css
   ...
   ```

3. Вернитесь в игровой режим.
4. Откройте Quick Access (кнопка `...`) → **Decky** → **CSS Loader** → **Refresh**.
5. Включите тему **Wii U Menu**.

Если темы нет в списке — проверьте, что `theme.json` лежит именно в корне папки `WiiUMenu`, а не на уровень выше.

### Копирование по сети (необязательно)

Если включён SSH на Deck:

```bash
scp -r WiiUMenu deck@<IP-адрес-deck>:/home/deck/homebrew/themes/
```

## Настройки темы

После включения в CSS Loader появляются параметры:

| Параметр | Варианты | Что делает |
|---|---|---|
| **Tile Shape** | Wii U Cards / Square Tiles (experimental) / Flat Cards | Форма плиток. Квадратные плитки — экспериментальный режим, перестраивает карусель. |
| **Background** | Wii U Light / Wii U Blue / Game Art | Светлый фон, насыщенный голубой или затемнённая арт-подложка выбранной игры. |
| **Header** | Frosted White / Transparent / Wii U Blue | Стиль верхней панели. |
| **Footer** | Wii U Wave / Flat White | Волна над нижней панелью или ровная белая полоса. |
| **Logo** | Wii U / Steam Deck / None | Надпись-бейдж в нижней панели. |
| **Watermark** | Wii U / Steam Deck / Off | Крупная полупрозрачная надпись в верхней части главного экрана. |
| **Font** | Nunito Rounded / Steam Default | Округлый шрифт (в комплекте) или родной Motiva Sans. |
| **Accent Color** | цветовой пикер | Цвет кольца фокуса и активной вкладки. |

Тема в первую очередь оформляет главный экран. Верхняя и нижняя панели при этом меняются на всех вкладках игрового режима, а библиотека и настройки остаются в родных цветах Steam.

Если хочется убрать бейдж «Wii U» внизу, выберите **Logo → None** — остальное оформление не изменится.

Если после обновления Steam что-то поехало:

1. Обновите CSS Loader в Decky.
2. Нажмите **Refresh** в CSS Loader.
3. Переключите **Tile Shape** на `Wii U Cards` — это самый безопасный режим.

## Как это устроено

Тема использует читаемые имена классов Steam (например, `gamepadhomerecentgames_RecentGamesInnerContainer_282X0`). CSS Loader сам подменяет их на актуальные хеши Steam, поэтому тема продолжает работать после небольших обновлений клиента.

Основные элементы:

- фон главного экрана — градиенты на `.gamepadhome_TabbedContent_cE1Sa`;
- арт-подложка игры скрывается, чтобы получить светлое меню;
- плитки — `.LibraryItemBox` внутри карусели;
- фокус — голубое кольцо через `.gpfocus`;
- волна — SVG в `::before` у `.footer_BasicFooter_3T1iF`;
- шрифт — локальный `Nunito` из папки `fonts/`.

## Превью

Откройте `preview/preview.html` в браузере на ПК. Это макет, а не скриншот с Deck: он показывает палитру, плитки, волну и нижнюю панель. В настоящем интерфейсе часы Steam остаются справа сверху, а бейдж «Wii U» находится по центру нижней панели.
